# 衣柜里明明有 99 件衣服，出门前还是觉得「没得穿」

这不是你不会穿，是没人告诉你**「为什么这一套行，那一套不行」**。

网上的穿搭内容大多是两种：要么给你一张「老钱风必备 10 件」的清单，要么夸你「这件好好看」。可真到了要出门的时候，这两样都用不上——你不会因为知道「老钱是米白驼色」，就穿对老钱。

这个项目想解决的就是这一件事：

> **在你出门前告诉你：这套到底行不行。不行的话，问题出在哪一件。**

---

## 它到底能帮你干什么

想象你今天要去见一个传统行业的客户。你衣柜里有冲锋衣、有西裤、有件穿了五年的灰卫衣。

普通的穿搭建议会说：「西裤配衬衫最稳。」

这个会说：

> **西裤对，但你的衬衫还在干洗店。那天你只有冲锋衣。**
> **冲锋衣不能上这个场合——它是机能体系的壳，在会议室里读起来像「这人不重视」。**
> **所以不是「冲锋衣+西裤凑合一下」，是这套方案在你这件衣服上不成立。要么去买一件能穿的衬衫，要么这个客户你换天见。**

它不哄你。它会拦住你，然后指给你看是哪一件出了问题。

这就是它最大的用处——**不是让你多买衣服，是让你少穿错一次。**

---

## 它凭什么知道

五个风格，每个都写到了能直接动手的程度。

| | 风格 | 一句话 | 最容易翻车的地方 |
|:--:|---|---|---|
| `CM` | **商务正装** | 让对方觉得你重视他 | 穿成从别人身上借来的 |
| `OM` | **老钱** | 不用证明自己有钱 | 全身都在解释「我很有品」 |
| `DT` | **黑暗机能** | 跟天气、城市、重力较劲 | 像 cosplay |
| `AV` | **美式复古** | 能解释成「当年人就这么干活」 | 显假——不是旧，是假 |
| `JM` | **日系极简** | 松着，但还有形状 | 显「没穿好」 |

**这张表是全项目最有用的部分。**

因为你可能认不出「这算不算老钱」，但你一眼就能认出「这人是不是在硬撑」。

大部分的穿错，都不是衣服本身丑，是**你觉得自己在一头，别人却读成了另一头**。这个项目教你的，就是提前知道自己会被读成什么样。

## 具体能问到什么程度

这些东西都是写死在里面的，不是每次临时编：

- **这件算哪个风格？** —— 「深蓝色无 logo 铜扣工装外套，穿去创意园路演行不行」
- **两件不同体系的能不能拼？** —— 「西裤 + 乐福鞋 + 原牛夹克，想搭成日系」
- **这个颜色到底几个算多？** —— 老钱：全身主色两个，第三个只能是点缀
- **这个场合能不能穿这个？** —— 三天的出差，见客户、路演、爬山三个场景怎么排
- **手里就这 99 件，能凑出几套？** —— 按场合排，排完告诉你缺哪一件

它甚至会告诉你**先买哪个**。不是列一堆想让你全买，是排个先后：买这件，你明天就能出门；买那件，还得再等一样东西。

## 它跟别的穿搭内容不一样在哪

**第一，它会说不。**

大部分 AI 被问「我这套行不行」，都会说「行啊，很精神」。这个不会。它有明确的硬禁忌，触线了直接判不成立，还会说清楚为什么。

**第二，它不会为了迁就你的一件衣服，把整个场合搞砸。**

衣柜里只有一件冲锋衣，是很容易带着「冲锋衣」去找场合，然后硬把整套调子改成机能的。

它的规矩很死：**场合定主调，衣服只能决定让步。** 衣服进不了这个场合，路只有两条——不上场，或者压到最外层。没有第三条「凑合一下」。

**第三，它知道自己哪儿不靠谱。**

每条规则都标了来源等级：

- `[物证]` —— 有官方或一手出处（比如 Levi's 官方档案里的 501 门襟、ACRONYM 官网的型号编码、西装的扣位规则）
- `[推断]` —— 从这些资料里反推出来的可执行写法
- `[归纳]` —— 通行说法，没找到成文出处

而且说实话：**这里面绝大多数是「推断」。**

所有具体数字——「裤长不超裆线 8 厘米」「肩线外扩 2 到 6 厘米」——都是从资料反推出来的执行建议，不是行业标准。别拿去当实测数据跟人争。

每个风格包的最后还专门有一节叫「这个风格的局限」，自己交代自己哪儿不行。老钱包就是老老实实标着「不是从网上蒸馏的，是基于服饰常识和行业共识写的」。

**一个不敢说自己短板的建议，你也不该信它的长板。**

## 怎么用

它本质上是一个给 AI 用的「说明书」——装进你常用的 AI 里，它就会按这套规矩跟你说话。

**用起来大概是这样：**

1. 先花十分钟把衣柜录一遍，每件衣服给个编号（`W001`、`W002`……），写清楚颜色、材质、版型、正式度
2. 之后每次问穿搭，直接说编号或者描述，它按编号给你排

记录方式很笨，但很省事：**录一次，以后所有方案都用编号说话。** 不用每次重新描述你有哪些衣服。

**装上之后，第一句可以这么问：**

> 「我明天要去见一个传统行业的客户，穿什么？我衣柜在档案里，帮我排一套，说清楚为什么。」

```bash
git clone https://github.com/<你的用户名>/wardrobe-stylist.git
```

放进 AI 的 skill 目录就行。

如果你不想装整套，只想复制一段话让它照着做：

- `references/system-prompt-v2.md` —— 熔炼版，约 2200 字，短，但该有的都有（推荐先试这个）
- `references/system-prompt.md` —— 完整版，解释最全
- `references/system-prompt-lite.md` —— 极简版，还没测过

**你的衣柜记录不会跟着仓库走。** 仓库里只有一张空白模板，每个人的衣服留在每个人自己那儿。
