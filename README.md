# wardrobe-stylist

> 一个会**拒绝**你的穿搭 AI。
>
> 不是因为它不懂，是因为它知道：**「这件好看吗」根本不是问题。**

穿搭问题的真身从来不是好不好看，是——**这套衣服，在我这个场合、这个衣柜、这具身体上，成立还是不成立。**

绝大多数穿搭建议都在回避这个问题。它们给风格描述：老钱是米白驼色、机能是黑色多口袋、复古是水洗丹宁。可你不会因为知道「老钱是米白」就穿对老钱。**描述不能执行。**

所以这里没有「十件必备单品」，也没有「今年流行色」。只有三层东西：

**判据 · 硬禁忌 · 冲突仲裁**

一件衣服归哪个包，两件不同体系的单品能不能拼，这个场合到底允不允许穿这套，遇到冲突听谁的——每一条都有明确顺序，不用每次重新争。

```
> 我想拿冲锋衣配西裤去路演。
✗ 不成立。冲锋衣归「黑暗机能」，西裤归「商务正装」，硬隔离。
  两头的判据不共存：一个在对抗环境，一个在请求尊重。
  让步项只能是冲锋衣；要么它不上场，要么把它压到最外层。
```

**它敢说不。这是它唯一的卖点。**

---

## 五个包，五种失败

每个包都不是按「长什么样」分类的，是按**它们各自会怎么失败**分类的。大部分穿搭事故，是穿着的人以为自己在一头，别人读成了另一头。

| ID | 包 | 一句话内核 | 它怎么翻车 |
|:--:|---|---|---|
| `CM` | **商务正装** | 让对方感到被尊重 | 像借来的西装 |
| `OM` | **老钱** | 不用证明自己 | 看起来一直在解释自己 |
| `DT` | **黑暗机能** | 每个变量都在跟环境较劲 | 像 cosplay |
| `AV` | **美式复古** | 能解释成「当年人这么干活」 | 显「假」——不是旧，是假 |
| `JM` | **日系极简 / City Boy** | 松下来还有形状 | 显「没穿好」 |

**这五种失败长相，比五段风格描述有用得多。** 你不会照着"老钱是米白驼"穿对老钱，但你能一眼认出「这个人是不是在解释自己」。

## 为什么它不会给你一锅乱炖

五个包，最大的灾难点不是哪个包写得不够细，是**调度**。

一个手上只有一件冲锋衣的人，会让你把整套方案围着他的冲锋衣排——然后把场合硬塞进去。这是最容易犯、也最容易被看穿的错。

拆开它只需要一句话：

> **场合定主判包，单品只决定让步。**
> 主判包不改，只让单品降级。单品的出路只有两条：
> **不上场，或者压到最外层 / 最内层。**

这句话写成了硬规则，放在 `references/router.md` 的三层仲裁里。违反它的唯一表现就是——为了穿某件衣服，把整套的调性改掉。

**有了这条，五个包才不是五本互相打架的小册子。**

## 证据分级：它知道自己哪里不靠谱

全仓库强制三级标注，不许含糊：

| 标记 | 含义 | 例子 |
|:--:|---|---|
| `[物证]` | 一手/官方来源 | ACRONYM 型号编码表、Levi's 501 门襟档案、西装扣位规则 |
| `[推断]` | 据物证反推出的可操作判据 | 「肩线外扩 2–6cm」「衣长不超裆线 8cm」 |
| `[归纳]` | 通行判断，无成文出处 | 老钱「太新也是越界」、复古「新旧落差」 |

**必须说清楚的一件事：这里绝大多数的穿搭规则是 `[推断]`。**

所有版型阈值——「裆线以下 8cm」「肩线外扩 2–6cm」「撞色 ≤1 处」——都是从物证反推出的可执行化数字，**不是行业标准，别当成实测数据引用**。

每个包的第 ⑨ 节叫「这个风格的局限」，专门写自己哪儿不行：

- `OM` 老钱包**不是网上蒸馏的**，是基于服饰常识与行业共识写的
- `JM` 包核心原则来自第三方转述——《POPEYE》官网、AH.H 官网、MUJI 官网**全部抓取失败**
- `AV` 包品牌商品页被反爬，当季 875 的鞋楦差异无法确认，**建议线下试穿**

一个不敢写自己短板的提示词，你也不该信它的长板。

## 装进去

```bash
# 整个放进 Agent 的 skill 目录
git clone https://github.com/<你>/wardrobe-stylist.git

# 或者只要单文件版：
#   references/system-prompt-v2.md  ← 熔炼版，约 2200 汉字，含路由
#   references/system-prompt.md     ← 完整版，解释最全
#   references/system-prompt-lite.md ← 极简版
```

然后按 `references/wardrobe-schema.md` 建一份自己的衣柜档案，编号固定（`W0xx–W5xx`），之后所有方案都用编号说话。

> 衣柜档案不随仓库发布。仓库里只有 `wardrobe.example.json` 模板——**你的衣服是你的事。**

