# 风格包：黑暗机能（Dark Techwear）

> 证据等级标注：**[物证]** = 有一手来源 · **[共识]** = 圈内通行说法、本次未取得原帖 · **[推断]** = 我据此归纳
> 本包不点名任何品牌好坏。点名需要可核验的圈内评判来源，没有就不写。

---

## ① 定位

**它是什么**：把服装当作**可挂载、可拆卸、可堆叠的系统**来设计，视觉上统一压低饱和度，让功能件在生活场景里也不显得突兀。

**它不是什么**（先破除三个最大误解）：

1. **不是「黑色 + 多口袋」**。这是最普遍的误解，也是本包反例的主要来源。
2. **不是户外冲锋衣的日常版**。这是第二普遍的误解——户外与机能的目标相反：户外追求极端环境下的保护，机能追求城市里的体面与应变。
3. **不是越贵越机能**。【物证】ACRONYM 纯棉工装裤 1,606 欧，比同品牌 3L GORE-TEX Pro 硬壳（1,329 欧）还贵。价格反映品牌与工艺，不反映功能强度。

**一句话判据**（本包的核心）：**看它有没有把「怎么做到的」写出来。**
写面料供应商、写层数、写结构术语 = 真机能；只写「防风防水科技面料」 = 机能风外观。

## ② 辨识锚点（5 条）

| # | 锚点 | 为什么能认出 |
|---|------|-------------|
| 1 | **面料有名有姓** | 【物证】ACRONYM 型号后缀直接就是面料代号：`-GT`=GORE-TEX、`-DS`=schoeller Dryskin、`-CV`=UHMWPE、`-E`=Encapsulated Nylon、`-M`=Nylon Stretch、`-PS`=Powerstretch Alpha、`-KI`=棉 |
| 2 | **结构术语而非形容词** | 【物证】官网页面上是 `Articulated`（立体/关节化剪裁）、`Encapsulated`、`Detachable Entry Cargo Pocket`、`Modular Peripheral Pocket`、`Tec Sys` |
| 3 | **黑色是基准不是卖点** | 【物证】官网几乎全线 `black`，没有把「黑」当卖点写 |
| 4 | **穿在身上能动手** | 【共识】**色调统一但不单薄**。抬臂不上提衣摆，蹲下不夹裆，坐下口袋不硌腿 |
| 5 | **可拆可挂** | 【物证】`Modular Peripheral Pocket`、`Tec Sys` 这类可挂载系统是体系的一部分，不是装饰 |

## ③ 核心要素（四维）

### 颜色

| | 内容 |
|---|---|
| 允许色域 | 冷调、低饱和。黑、炭灰、深灰、石墨、冷深绿、深藏蓝 |
| 主色 | 黑 / 炭灰（占全身 70% 以上） |
| 点缀色 | 安全橙、荧光绿、机能绿、钢灰。**占比 ≤10%**，且只出现在小面积（拉链头、内衬、鞋底、logo） |
| 禁用色 | 暖米白、驼、卡其（老钱风的地盘）、正红、宝蓝、粉彩 |
| [推断] 为什么 | 这套体系的价值来自「暗」与「冷」，暖色一进来就掉出体系；亮色一旦超过 10% 就从「机能」滑向「赛博」。 |

### 材质

| | 内容 |
|---|---|
| 欢迎 | 尼龙（涂层/无涂层）、GORE-TEX 系膜材、Cordura、schoeller Dryskin、四面弹尼龙、P棉、抓绒（作为内层） |
| 禁区 | 羊毛（尤其精纺）、真丝、亚麻、羊绒、法兰绒、亮面缎、蕾丝 |
| 灰区 | 纯棉【物证】ACRONYM 自己出一千六百欧的纯棉工装裤，所以纯棉**不违规**——但要看**版型和工装基因**，而不是棉质卫衣的休闲感 |

### 版型

| | 内容 |
|---|---|
| 欢迎 | H型直筒、微宽、锥形收口、束脚、立体剪裁（裆部/膝部有结构线） |
| 禁区 | 紧身、大喇叭、低腰、过度 oversize（会滑向滑板风） |
| [共识] 裤口规则 | 机能裤**必须收口或能束脚**。裤脚敞着盖住鞋面 → 掉出体系，变成休闲工装 |

### 细节

| | 内容 |
|---|---|
| 欢迎 | 压胶、拆装式口袋、织带、扣具（Fidlock/Cobra 类）、反光条、抽绳、防水拉链 |
| 禁区 | 水钻、刺绣、印花文字、复古做旧、破洞、麂皮拼接 |
| **[推断] 堆砌阈值** | **单件身上的「功能装饰元素」≤3 个**（口袋/织带/扣具/反光条各计 1）。超过 3 个且都不受力、不能真用 → 从机能滑向表演 |

## ④ 硬禁忌（7 条）

触发即判「不是这个风格」。

1. **不是「黑色版大牌」**——满身大 logo 的黑色单品，无论多贵，都不是机能。
2. **不是「多口袋战术」**——口袋平贴、无受力设计、只为看上去能装，这是战术风/军迷风，不是机能。
3. **不是「冲锋衣 + 西装裤」**——机能外套配老钱西裤的正式线条，两头都不成立。
4. **不是「机能裤 + 皮鞋/乐福」**——见仲裁 §⑦。
5. **不是「亮面全身滑」**——亮面是点缀不是主体。雾面占 70% 以上，亮面超过 30% 就滑向赛博/夜店。
6. **不是「配饰拉满」**——护目镜、面罩、战术背包一起上，就从穿搭变成 cosplay。【成文来源】Wikipedia「Cybergoth」记录这类元素源自哥特/锐舞派对装扮，与户外功能无关。
7. **不是「只穿黑的就对了」**——全黑且面料全是普通棉/涤，是「黑衣服」，不是机能。

## ⑤ 正例（6 套）

| # | 组合 | 为什么成立 |
|---|------|-----------|
| 1 | 硬壳（哑光，压胶可见）+ 锥形机能裤（收口）+ 大底靴 | 三件都在体系内：面料有膜、裤口收拢、鞋型够重 |
| 2 | 抓绒内胆 + 尼龙马甲（可拆）+ 直筒工装裤 + 低帮战术靴 | 靠「可拆」这个结构性特征成立，不靠堆装饰 |
| 3 | 深灰卫衣（雾面、无大 logo）+ 束脚裤 + 机能跑鞋 | 最低门槛的日常机能，靠版型和收口稳住 |
| 4 | 长袖打底 + 可挂载外披 + 铅笔裤 …… | 用模块化单品做重心，其余克制 |
| 5 | 全黑三层叠穿（打底/中层/外壳），仅靠压胶线与反光条破黑 | 靠材质差异而非颜色差异制造层次，这是机能的真功夫 |
| 6 | 机能外套 + 同色系工装裤 + 安全橙配件（一处） | 点缀色 ≤10% 且只有一处，符合 §③ 配色纪律 |

## ⑥ 反例（6 套）——每一套都和正例只差一步

| # | 看起来像 | 越界在哪一步 |
|---|---------|-------------|
| 1 | 快时尚「机能系列」：黑卫衣 + 多口袋工装裤 | 越在**面料**——没有膜、没有层数、只有口袋。差一步：换成有膜或有压胶的外壳 |
| 2 | 机能外套 + 黑色西装裤 + 乐福鞋 | 越在**下半身**。上半身对了，下半身的正式线条把体系拉走 |
| 3 | 全套亮面 PVC + 护目镜 + 面罩 | 越在**表演性**。这是 cybergoth 的派对符号，不是城市机能 |
| 4 | 硬壳 + 运动短裤 + 白袜厚底鞋 | 越在**场景**。壳在做防护，下半身在打网球 |
| 5 | ACRONYM 纯棉工装裤 + 无膜卫衣 + 帆布鞋 | 越在**只有品牌没有功能**。品牌是真的，这套衣服不是 |
| 6 | 机能马甲 + 印花 T + 破洞牛仔 | 越在**细节语汇冲突**。机能语言与街头破坏感互斥 |

## ⑦ 冲突仲裁（明确秩序，不和稀泥）

用户想要机能，但衣柜/单品只符合别的风格时，按此顺序裁决：

**原则：宁缺毋滥。给「现有最接近方案 + 明确缺口」，绝不硬凑四不像。**

| 情形 | 裁决 |
|------|------|
| 衣柜只有机能裤，没有机能外套 | **不硬凑**。输出：用机能裤配现有最好的深色上装（哪怕是普通卫衣），并明确写「缺一件哑光硬壳或风衣，这是本风格的骨架」 |
| 用户要机能，但全身只有老钱单品 | 直说：这两套体系互斥。问用户是**先补一件机能外壳**，还是**换成老钱方案**。不要混搭 |
| 单品是真机能品牌，但无功能（如纯棉工装裤） | 允许入场，**但不得当作「功能层」**，只能当裤子用。不能因此宣称这套有防护性 |
| 机能外套 + 老钱西裤（冲突） | 优先保外套，换下装。若用户坚持，直接判「不成立」并说明 |
| 机能 + 运动鞋（非机能鞋型） | 允许，但**必须是低帮、线条干净、无夸张缓震块**。大厚底跑鞋会拉向运动风 |
| 颜色上想加一个亮色 | 允许一处，≤10%。超过一处即拒绝 |
| 用户明确说「我就要好看不要功能」 | 接受，但**改称「机能风外观」**，不冒充真机能。诚实标注 |

## ⑧ 置信度信号

判断一件单品属不属于本风格时：

| 置信度 | 条件 |
|--------|------|
| **高** | 能看到面料标识（有膜名/层数/面料编号）**且**结构特征明确（收口、压胶、立体剪裁） |
| **中** | 结构特征齐，但面料看不到或只写「防水面料」 |
| **低** | 只有颜色和口袋，拿不到任何面料或结构信息 |

**低置信度时必须问，不许硬判**，且一次最多问 2 个：
- 「这件面料标签上有写具体膜或面料名吗？（比如 GORE-TEX / 尼龙 / 克重）」
- 「裤脚是收口/能束脚，还是敞着的？」

问不出来 → 标「未确认」，按「机能风外观」处理，不按真机能。

## ⑨ 这个风格的局限（诚实边界）

1. **不适合高温**。全黑 + 涂层，夏天基本穿不住（除非选薄款 Dryskin 类）。
2. **不适合正式场合**。正式度天花板大概到 3.5/5，正装场合它帮不上。
3. **成本高**。真机能的骨架件（外壳）是一笔真投入，便宜替代品会直接跨回「外观」。
4. **圈子内部对「什么是真机能」没有统一标准**。本包用的是「可测指标」这条线，圈内也有人按别的线划。遇到分歧以指标为准。
5. **本包的批评部分证据偏弱**。第 ⑨ 段第 4 条、§④ 第 6 条的完整原帖未能取得（网络受限），已标 [共识] 的条目属于通行说法，非引文。

## ⑩ 与其他风格的关系

- **和老钱**：几乎互斥。共用的只有「低饱和、无大 logo、质感优先」这条底线，其余全反。**必须分模式，不可混搭。**
- **和户外**：同源但目标不同。户外追求极端保护，机能追求城市应变。户外单品可以进机能，但要收掉「登山logo + 高饱和」。
- **和赛博/哥特**：渊源上相邻（见 §④ 第 6 条），但机能要求「城市日常成立」，赛博不要求。这是分界线。
