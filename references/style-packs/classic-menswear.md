> 证据分级：`[物证]` = 一手/成文来源（维基成文条目、博物馆藏品条目、署名媒体）；`[推断]` = 我据 `[物证]` 反推的可操作判据；`[归纳]` = 圈内通行判断，本次未取得成文出处。

## ⓪ 边界：什么时候用它，什么时候必须用老钱

老钱包和本包在正式度 4–5 分**确实重合**，重合区里选错不会「难看」，只会「不对」。所以边界不能靠正式度分，要靠**场合在评估什么**。

### 硬隔离带：一句话

> **正装是「被评估」，老钱是「被印象」。**

- **有人拿标准衡量你**（考官在打分、对方在判断你够不够格、镜头在拍）→ **商务正装**
- **有人只是打量你**（看你得不得体、舒不舒服、是不是个靠谱的人）→ **老钱**

### 怎么判：问自己「这场合有没有人在核对你」

| 场合 | 有人在核对吗 | 用哪个包 |
|---|---|---|
| 面试（金融、法律、咨询、体制内） | **有**，HR 和面试官在按行业标准判断 | **正装** |
| 提案 / 谈判 / 路演 | **有**，客户在判断你的专业度 | **正装** |
| 法庭、正式听证 | **有**，规则明确 | **正装** |
| 领奖、正式颁奖礼、致辞 | **有**，有镜头和流程 | **正装** |
| 葬礼 | **有**，礼仪有硬规矩 | **正装**（深色、无配饰炫耀） |
| 见对方父母 | **没有**，对方在看「这人怎么样」 | **老钱** |
| 朋友婚礼（非本人主役） | **没有**，不能抢主角 | **老钱** |
| 周末高级餐厅、看展、朋友聚会 | **没有** | **老钱** |
| 公司日常（非会议日） | **没有** | **老钱** |

### 重合区里怎么拆：看外套的「骨」

正式度 4 分左右，两包都穿得住。这时按**外套的硬度**判：

| 外套长什么样 | 归哪个包 |
|---|---|
| **有垫肩、有 canvas 衬、硬挺的西装外套** | **正装**（哪怕里面配得随便，外套会把它拉回来） |
| **无衬、软塌、针织、亚麻、羊绒质地的外套** | **老钱** |

理由 `[物证]`：西装外套的「形」来自 canvas 衬而非粘合，`"Shape is the essential part of tailoring"`（维基 Suit）。**一站上肩就撑起来的外套，本身就是「在证明自己够格」。**

### 三条例外（重合区里反悔）

1. **场合里有明确点名的着装要求**（invitation 上写了 black tie / business formal）→ **一律按正装**，不看其他
2. **用户自己说「我要穿得正式一点」但没说场合** → **问一句「这场合有谁在看你、看什么」**，不要替他选
3. **用户要去的是「面试」两个字** → **一律正装**。面试默认有标准，而且标准比对错的代价高得多

### 一句话给用户

> 这不是「谁更正式」的问题，是「对方在核对还是在感受」的问题。**核对用正装，感受用老钱。**

## ① 定位

**正装是一套可被检验的规则系统，不是一种感觉。**

它跟前两个包最大的区别：机能和老钱都在回答「这件东西好不好」，正装在回答「**这一步做对了没有**」。合身有对错，扣位有对错，袖口露出多少有对错。**它的失败方式不是「不好看」，是「露怯」。**

三个误解：

1. **不是「越贵越对」**——成衣可以很对，定制可以很错。规则对了，平价西装比错尺寸的高定体面
2. **不是「黑西装最正式」**——黑西装配日常场合经常过头；深藏蓝是大多数商务场合的标准答案，纯黑更多属于葬礼和晚宴 `[物证]`（维基 Black tie/Formal wear 体系里 black lounge suit 属 semi-formal 档，与 black tie 并列而非更正式）
3. **不是「上班才穿」**——它的规则来自礼服体系，面试、葬礼、领奖都算，这些场合的规矩比办公场合严

---

## ② 辨识锚点

判断一套正装做对没做对，看这五处，**从最容易看出问题的往后排**：

1. **肩**：肩线要落在自己的肩点上，不垂下、不外扩。这一处错了，整套的价签都救不回来
2. **领**：后领贴不贴脖子。低头看会不会露出后颈一道缝
3. **扣位**：中心扣是否对着自然腰线。扣位过高显短，过低显腿短、腰粗 `[物证]`
4. **袖**：衬衫袖口露出来一点，且露出量跟后领露出量大致一致 `[成文]`
5. **长度**：外套下摆盖住臀部，但不超过指关节 `[归纳]`（成文材料只说「回归传统衣长」，没给数值）

## ③ 核心要素

### 颜色

- **标准答案**：深藏蓝（navy）> 炭灰（charcoal）> 中灰。**一套深藏蓝是你的第一套，不是黑**
- **纯黑西装**：留给葬礼、正式晚宴、以及少数要求全黑的场合。日常商务穿黑西装容易穿成制服或婚庆 `[归纳]`
- **棕色、绿色、浅灰**：可以入，但属于「第二套」，不适合最硬的场合
- **禁**：亮面、反光面料、大面积格纹、条纹做得太宽或太亮、任何印花

### 材质

- **首选**：精纺羊毛（worsted wool），四季常穿；夏季可用 Fresco / 高捻纱、羊毛麻混纺
- **结构**：能看出有衬（canvas 或半衬），不是薄薄一层粘合布 `[物证]`——形来自衬
- **禁**：涤纶比例过高（会反光）、亮面缎、皮、牛仔、任何会「闪光」的面料
- **检验 `[推断]`**：手指捏住面料松手，回弹快、发亮、有沙沙声的，多半化纤偏高

### 版型（这里全是自检动作，不是尺寸）

> **重要**：以下全部是 `[推断]` —— 成文材料只给了定性标准「无张力褶皱、balanced silhouette」`[物证]`，这些动作是我按这条反推的。**用户没有软尺也能做。**

| 检查 | 怎么做 | 不合格的信号 |
|---|---|---|
| **肩** | 穿上站直，让人从正面看，或正对镜子 | 肩线垂到上臂外、袖子在肩点鼓起、肩线比自己的肩点宽出一指以上 |
| **胸口** | 扣上中心扣 | 胸口出现 **X 型拉扯褶皱**；扣子绷得紧；驳头往外翻、离开胸口 |
| **扣位** | 扣上后看扣子是否在腰最细处 | 扣位过高（肚子以下全是腿，上身显短）；过低（腰显粗、眼被往下拉 `[物证]`） |
| **下摆** | 扣上后抬双手 | 下摆跟着往上翘起一大截、变成「八字」——说明胸围或袖窿不够 |
| **后领** | 低头 | 后颈露出一道缝 → 领子没贴脖子 |
| **背** | 背对镜子找肩胛处的斜褶 | 有斜向的放射状褶皱 → 肩背松量不对 |
| **袖长** | 双臂自然下垂 | 衬衫袖口看不到；或露出超过 2 cm 像在借衣服 |
| **坐下** | 坐下再站起 | 后背绷紧、扣子勒、要解扣才坐得下 → 紧了一号 |

### 细节（每条都有成文出处）

- **扣法 `[物证]`**
  - 单排两扣：**只扣上面那颗**，下面那颗本就不是为扣而裁的（扣了会破坏垂坠）
  - 单排三扣：扣**中间**那颗，最上一颗随你，最下一颗传统上根本没设计成能扣
  - 双排扣：典型 6 颗扣、其中 2 颗可扣；**最下一对是浮在搭门上的，不是用来扣的**；坐下通常不解
  - 站着扣、坐着解（双排扣例外）
- **驳头 `[物证]`**
  - 平驳（notched）：单排扣常见，三种里最不正式
  - 戗驳（peaked）：通常配双排扣；单排扣戗驳是裁缝里最难做的活之一
  - 青果领（shawl）：只属于晚礼服（tuxedo/dinner suit）
  - 宽度：唯一的比例锚点是「延伸到衣领线与肩线中点的稍内侧」，**是按肩宽定的，不是按胖瘦**
  - 领带宽度跟随驳头宽度
- **袖口 `[物证]`**：barrel cuff（纽扣式，标准）< French cuff（折回用袖扣，较正式）< single cuff（不折回用袖扣，**最正式，只配 white tie**）
- **腰带与背带 `[物证]`**
  - 礼服（black tie / white tie / morning dress）**一律不系皮带**，用吊带或高腰裤
  - 普通日常西装（lounge suit）**没有**强制禁令——但背带在结构上更对：从肩受力，裤子能定在正确位置
- **开衩 `[物证]`**：双衩（英式）、无衩（意式）、单衩、钩形衩（美式 Ivy）；晚礼服传统无衩

### 鞋

- **黑色牛津鞋**是唯一不会错的选择；德比鞋次之；乐福鞋在正式场合偏休闲
- **禁**：球鞋、厚底、尖头亮面、任何雕花（brogueing）配 black tie `[物证]`：`"brogueing should never be seen"`
- **鞋的状态优先于款式 `[归纳]`**：鞋跟磨斜、鞋面不保养，整套都救不回来

## ④ 硬禁忌

1. **扣错扣子**——单排两扣扣下面那颗、三扣扣最下面那颗，等于当场让人看出不熟规矩 `[物证]`
2. **系皮带配礼服**——black tie / morning dress 一律禁止，这条没有例外 `[物证]`
3. **扣着西装坐下**——会把扣子和下摆一起撑开，且坐下前就该解开
4. **袖口不露或露太多**——看不到衬衫袖口是失误，露超过 2 cm 是衣服不合身
5. **运动鞋 / 球鞋配西装**——除非场合明确允许 smart casual，否则不是「休闲」，是错
6. **三件套+双排扣+戗驳+袖扣+口袋巾全上**——所有层级都在说话，等于没有重点
7. **亮面面料**——反光的西装在任何光线下都显廉价

## ⑤ 正例（5）

1. **标准面试装**：深藏蓝单排两扣 + 白衬衫 + 深灰领带 + 黑牛津鞋
   成立点：全套不出错，藏蓝是商务标准答案
2. **保守行业/体制内**：炭灰单排两扣 + 浅蓝衬衫 + 深蓝领带 + 黑德比
   成立点：比藏蓝更低调，灰比蓝更不容易出错
3. **夏季商务**：中灰高捻羊毛单排 + 白衬衫（法拉绒领）+ 深色针织领带 + 黑牛津
   成立点：面料轻但仍是精纺，不靠亚麻撑场面
4. **正式晚宴（black tie）**：无衩晚礼服 + 白衬衫（single cuff + 袖扣）+ 黑领结 + 黑丝缎腰封 + 黑漆皮牛津
   成立点：全套照 black tie 的成文规矩走，一处不错
5. **葬礼**：纯黑或深藏蓝西装（无衩更好）+ 白衬衫 + 纯黑领带 + 黑鞋
   成立点：**不用任何配饰说话**，连口袋巾都不放

## ⑥ 反例（5，每套只差一步）

1. **黑西装 + 白衬衫 + 银灰领带（日常上班）** → 越界在**颜色**：黑西装在日间场合偏葬礼、偏晚宴，商务日常应该用藏蓝或灰
2. **深藏蓝西装 + 白衬衫 + 运动鞋** → 越界在**鞋**：整套前六件都对，最后一双把规矩全推翻
3. **两扣西装扣了下面那颗** → 越界在**规则**：衣服本来是照「扣了就破坏垂坠」裁的 `[物证]`
4. **戗驳双排扣全套 + 口袋巾 + 漆皮鞋去面试** → 越界在**过载**：面试要的是「不出错」，不是「很讲究」
5. **尺码小一号的修身西装 + 紧绷胸口** → 越界在**合身**：扣上之后胸口出现 X 型拉扯，这条比任何款式都致命

## ⑦ 冲突仲裁

| 情形 | 裁决 |
|---|---|
| 只有一套，不确定穿它对不对 | 先问「有没有人拿标准核对」；有 → 正装，没有 → 考虑老钱。**不确定就按正装，正装容错率高** |
| 全身正装但鞋不配 | 鞋是硬性最后一道，宁可不穿这套。缺口写「缺一双黑牛津」 |
| 场合介于 business formal 和 business casual | 拆一层：脱外套或换领带。**外套在就是 formal，不在就是 casual** |
| 用户要去葬礼 | 按正装规则，但**颜色只留黑/深藏蓝，配饰全下**，连领带夹都不要 |
| 夏天太热 | 不许用亚麻替代精纺，可以换高捻薄羊毛。真穿不住就脱外套，但里面还得是衬衫打领带 |
| 用户想穿得「有个性」 | 个性放在细节上（袖扣、领带、方巾），不放在结构上（驳头形状、扣位）。结构是个性的禁区 |
| 和老钱包重合（4–5 分） | 看外套硬度：有垫肩硬挺 → 正装；软塌无衬 → 老钱 |
| 用户说他那行没人这么穿 | 尊重行业实际，但**第一次见客户、第一次面试永远先按最保守的来** |

## ⑧ 置信度信号

- **高**：能看到外套肩线、扣位、驳头形状，且知道场合
- **中**：只看得到颜色和大致版型，场合明确
- **低**：只有照片、场合不明、不知道行业惯例

低置信度：**不要给「对/错」判定**，改成给「两种可能和各自的后果」。例如「如果对方是体制内，穿藏蓝两扣最稳；如果是创意行业，穿这套会显得用力过猛」。

## ⑨ 局限

1. **肩线、胸围松量、衣长的量化标准完全未取得**——本包里所有合身判断都是自检动作，不是尺寸数据。不许对用户说「你的胸围应该是多少」
2. **场合规则地区差异大**——英美、日韩、中国体制内和民企的标准各不相同，本包偏英美保守标准
3. **不服务于非二元体型**——现有成文资料几乎全是传统男装体系，对跨性别或中性穿着的问题，本包只能给「这套规则本身有历史包袱」的提醒，不作为依据
4. **跟不上时尚变动**——驳头宽度、扣位高低、衣长每十年换一轮，本包的锚点是「不随时间变的规则」（扣法、礼服禁令），潮流部分只作为参考
5. **证据天花板**：规则部分能标 `[物证]`，量体部分只能标 `[推断]`。**引用合身建议时，不许把它说成「标准」**

## ⑩ 与其他风格包的关系

| 关系 | 说明 |
|---|---|
| **vs 老钱** | 重合区在 4–5 分。拆法看「核对 vs 感受」和「外套硬不硬」。**正装是证明自己够格，老钱是不需要证明** |
| **vs 黑暗机能** | 几乎不共存。唯一交集是「干净的黑色通勤装」，但那既不是正装也不是机能 |
| **vs 内部更细的档次** | 本包内部还分 white tie / black tie / morning dress / 商务正装 / smart casual 五档。**用户说「正式」时先确认是哪一档**：invitation 上写了字就照写的来，没写就按场合最保守的猜 |

### 五档速查（`[物证]` 维基 Dress code 阶梯）

| 档 | 男装标准配置 | 关键禁令 |
|---|---|---|
| White tie | 燕尾服 + 白领结 + 白马甲 + 单袖口袖扣 | 马甲不得露在燕尾服前摆下方；上浆衬衫 |
| Morning dress | 晨礼服 + 条纹裤 + 灰领带/领巾 | 裤脚**不许翻边**；**不许系皮带**；配灰色高帽 |
| Black tie | 无衩晚礼服 + 黑领结 + 丝缎腰封 | **不许皮带**；裤子无翻边；**鞋不许有雕花** |
| Business formal | 深藏蓝/灰单排 + 衬衫 + 领带 + 牛津鞋 | 腰带可有，但背带在结构上更对 |
| Smart casual | 拆开穿：外套不配同色裤 / 衬衫不配领带 | 没有硬禁令，但球鞋、牛仔裤是滑出的信号 |
