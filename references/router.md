# 多包路由字典（Router）

> 用途：系统里已有 5 个风格包。每次对话**不扫全包**，先用本字典定位「主判包」与「副判包」，只加载这两个。
> 证据分级沿用各包：`[物证]` 一手/官方 · `[推断]` 据物证反推 · `[归纳]` 圈内通行。
> 本字典自身的判据多数是 `[推断]`——它是**调度层**，不产生新的风格事实，只决定「去读哪个包」。

---

## 〇、五个包的 ID 与一句话内核（路由的锚）

| ID | 风格包 | 一句话内核 | 一句话失败长相 |
|---|---|---|---|
| `OM` | 老钱 Old Money | 不用证明自己 | 显得「在解释自己」 |
| `DT` | 黑暗机能 Dark Techwear | 每个变量都在跟环境较劲 | 像 cosplay / 像忍者 |
| `CM` | 商务正装 Classic Menswear | 让对方感到被尊重 | 像借来的西装 |
| `AV` | 美式复古 American Vintage | 能解释成「当年人这么干活」 | 显「假」 |
| `JM` | 日系极简 / City Boy | 松下来还有形状 | 显「没穿好」 |

## 一、任务 关键词 → 主判包

### 1.1 场合类（用户说「我要去…」）

| 关键词 | 主判包 | 副判包 | 依据 |
|---|---|---|---|
| 面试、终面、签约、谈合同、提案汇报 | `CM` | `OM` | 需要「被当成可靠的人」，正式度上限 |
| 见**传统**客户、体制内、行业协会、医院/律所/银行拜访 | `CM` | `OM` | 对方按正式度读人；`[推断]` |
| 见**创意**客户、路演、品牌方、设计师、投资人不强要求着装 | `OM` 或 `JM` | `DT` | 看对方行业；偏商务用 `OM`，偏创意用 `JM` |
| 婚礼（宾客）、葬礼、颁奖、重要晚宴 | `CM` | — | 硬场合，无副包 |
| 约会（第一次、正式）、见家长 | `OM` | `JM` | 「不用证明」= 不施压；`JM` 作为舒适备选 |
| 约会（日常、散步、咖啡） | `JM` | `OM` | 松弛感优先 |
| 聚会、朋友生日、看演出 | `JM` | `AV` | 看场地调性 |
| 看展、美术馆、街区散步、候机 | `JM` | `OM` | 重在日常感 |
| 通勤（办公室无着装要求） | `JM` | `OM` | — |
| 通勤（办公室要求西装） | `CM` | `JM` | 只能西装，但版型可借 `JM` 的宽松逻辑做 non-suit |
| 爬山、徒步、露营、越野、雨天长途 | `DT` | — | 功能优先，无副包 |
| 骑车通勤、冬季户外长时间 | `DT` | `JM` | 功能件 + 干净 |
| 居家、接机、随手出门 | `JM` | — | 最低门槛 |

### 1.2 单品类类（用户发一件衣服／说「我有一件 X」）

| 单品特征 | 主判包 | 副判包 |
|---|---|---|
| 冲锋衣 / 硬壳 / 压胶拉链 / 防水面料 | `DT` | `JM`（仅当它**无收纳无防护标**） |
| 多口袋工装裤、织带、MOLLE、可拆卸件 | `DT` | — |
| 西装外套（有结构、有垫肩、成套可能） | `CM` | `JM`（非成套、宽松版）、`AV`（粗花呢/猎装） |
| 有驳头、有扣位排列、需要与衬衫同穿的衬衫 | `CM` | — |
| 西裤（有褶、有调节扣、垂坠感强） | `CM` | `OM` |
| 原牛 / 赤耳 / 裆部铆钉 / 做旧水洗 / 皮靴（875 类） | `AV` | — |
| 粗花呢、油蜡布、灯芯绒、猎装夹克、针织马甲 | `AV` | `OM`（当颜色素净、无做旧时） |
| 阔腿裤 / 大码卫衣 / 落肩 / 重磅 T | `JM` | — |
| 高领内搭、弯檐帽、渔夫帽、白厚棉袜 | `JM` | — |
| 米/燕麦/驼/藏蓝，无 logo，面料是天然纤维 | `OM` | `JM`（若版型宽松） |
| 大 logo、反光材料、五金夸张 | `DT`（若功能向）或直接判「不属任何包」 | — |
| 速干／户外／运动化纤，但**无收纳无防护** | `JM` | `DT` |

### 1.3 「这件算哪个包」的硬判据（三步，按序执行）

> 这一步是**单品归属**，不是**场合归属**。两步都走，冲突才是真冲突。

1. **有没有收纳/防护结构？** 有 → `DT` 专属信号。仅功能性面料、无结构 → 归 `JM`。
2. **有没有明确年代工艺？**（铆钉、原始门襟、单针车线、鞋头缝线）有 → `AV` 专属信号。
3. **有没有「结构 + 正式度」？**（垫肩、驳头、成套可能）有 → `CM` 专属信号。
4. 以上都没有，只剩**颜色 + 面料 + 版型** → 用 **合身度** 分流：
   - 肩线贴合肩点、面料回弹慢 → `OM`
   - 肩线外扩 2–6 cm、面料有厚度 → `JM`

## 二、任务 双触发冲突的仲裁优先级

### 2.1 三层仲裁（从硬到软，有先后，不许并列）

```
第 1 层  场合底线（不可谈判）
        葬礼/婚礼/面试/签字会议 → CM 强制，其余全部让位
        户外运动/恶劣天气      → DT 强制
        ↓ 场合不设底线时
第 2 层  场合倾向（决定主判包）
        偏正式 → OM / CM
        偏日常 → JM
        偏年代 → AV
        ↓ 主判包已定，但用户手上单品属于别的包时
第 3 层  单品让步（不让主判包改，只让单品降级）
        强制规则：只能「减少该单品的出场」或「把它压到最外层/最内层」
        —— 绝不允许「为了用上这件单品，换一个主判包」
```

**第 3 层是这套系统的命门。** 违反它的唯一表现就是：为了穿某件衣服，把整套的调性改掉。这是 5 个包里最容易犯、也最容易被看出来的一种错。

### 2.2 冲突矩阵（行 = 场合，列 = 单品归属；格子 = 仲裁结果）

|  | 单品属 `CM` | 单品属 `OM` | 单品属 `DT` | 单品属 `AV` | 单品属 `JM` |
|---|---|---|---|---|---|
| **场合 `CM`** | 正常 | 可用，但**必须**外套/鞋二者之一为 `CM` | 拒用 | 拒用 | 拒用 |
| **场合 `OM`** | 仅鞋或包 | 正常 | 拒用（除雨具） | 可用一件，不许有做旧 | 可用，但版型要收窄 |
| **场合 `JM`** | 外套/裤二者之一 | 可用，肩线改宽松即可 | 可用**一件**，须无收纳结构 | 可用一件，须无做旧 | 正常 |
| **场合 `AV`** | 拒用 | 可用（素净） | 拒用 | 正常 | 可用一件 |
| **场合 `DT`** | 拒用 | 拒用 | 正常 | 可用（工装逻辑） | 可用一件内衣层 |

**「可用一件」的严格定义**：整身**只能出现 1 件**该归属的单品，且它不能是视觉焦点（不占最大面积、不占最强对比色）。

### 2.3 三条不可越界的硬隔离带

1. **`CM` 与其他任何包双向隔离**：`CM` 场合不接受任何其他归属的外套；其他场合也不接受 `CM` 的整套。
2. **`DT` × `OM` 完全不通**：一个在证明功能，一个在证明不需要证明。
3. **`AV` × `JM` 只靠「做旧」区分**：有做旧 = `AV`，干净 = `JM`。同一件衣服按状态分流，不看品牌。

### 2.4 当冲突无法裁定时怎么办（降级协议）

按序执行，不许跳步：

1. 反问一句**只问一个变量**的问题（例：「这件外套有外露的胸袋或织带吗？」）
2. 仍无法定 → **选正式度更高的那个包**（安全侧）
3. 仍无法定 → 输出 **A/B 两版**，各一行，标注各自代价，让用户选
4. **不许**输出「看你自己喜欢」这类不承担判断的话

## 三、路由执行流程（每次对话固定走这四步）

```
Step 1  抽取三个槽位：场合 / 身份（对方是谁）/ 单品清单
Step 2  场合查 §1.1 定主判包；单品查 §1.3 定归属
Step 3  主判包 == 全部单品归属 → 直接出方案（只加载 1 个包）
        不相等 → 走 §2.2 矩阵仲裁（加载 2 个包）
Step 4  出方案时，第一句必须写「主判包 + 本次让步的单品 + 让步理由」
```

**Step 4 是强制的。** 不写这句话，方案本身就是黑箱。

---

## 四、加载成本控制

- 一次对话**最多加载 2 个包**（主判 + 副判）。
- 用户只给场合、没给单品 → **只加载主判包**。
- 用户只给单品、没给场合 → **加载该单品归属包 + `JM`**（因为无场合时默认走最低门槛）。
- 用户同时给了场合和 5 件以上单品 → **先要场合，再要单品清单**，不许一次全开。

---

## 五、本字典自身的局限

1. 它是 `[推断]` 层：所有路由判据都不是任何风格包作者写下的，是我从各包的「辨识锚点」反推的调度规则。
2. 关键词表是**不完备**的：没出现在 §1 的词，按 §1.3 的四步硬判据走，不许硬套。
3. 场景优先级里「偏正式/偏日常/偏创意」的判断依赖对方身份，而对方身份**用户必须告诉我**，不许我猜。
