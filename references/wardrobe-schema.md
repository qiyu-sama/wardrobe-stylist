# 衣柜档案规范 v1

> 半结构化：你说人话，我落字段；落完回显给你确认。
> 这份文件是 Skill 读衣柜的唯一依据，改它不用改 Skill。

---

## 1. 编号规则

每件衣服一个编号，永不复用。

| 前缀 | 品类范围 |
|------|---------|
| W0xx | 外套 / 大衣 / 夹克 |
| W1xx | 上装（T恤、衬衫、卫衣、针织、马甲） |
| W2xx | 下装（裤、裙） |
| W3xx | 鞋 |
| W4xx | 包 / 配饰 / 帽 / 围巾 / 腰带 |
| W5xx | 连体（连衣裙、连体裤、套装） |

卖掉、扔掉、不再穿的，编号置 `retired: true`，**不删不covering**——这样以后能回答"我为什么不再穿它"。

---

## 2. 必填字段（8 个）

没有这 8 个，搭配质量就不稳。缺的标「未确认」，不空着充数。

| # | 字段 | 取值 | 说明 |
|---|------|------|------|
| 1 | `category` | 见上表 | 品类 |
| 2 | `color` | 主色 + 色相族 | 例：`黑/冷黑`、`藏蓝/冷`、`驼/暖` |
| 3 | `material` | 主材质 | 例：`尼龙三合一涂层`、`美利奴羊毛` |
| 4 | `silhouette` | 版型 | 例：`H型直筒`、`宽松oversize`、`修身` |
| 5 | `weight` | 厚薄 + 季节 | 例：`中厚/秋春`、`轻薄/夏` |
| 6 | `formality` | 正式度 1–5 | 1=运动宅家，3=日常通勤，5=正装场合 |
| 7 | `condition` | 状态 | `新` / `尚可` / `旧` / `起球` / `褪色` / `变形` |
| 8 | `constraints` | 搭配限制 | 例：`袖口磨白，别配浅色`、`亮面反光，不进老钱` |

---

## 3. 可选字段

| 字段 | 说明 |
|------|------|
| `brand` | 品牌 |
| `bought_at` | 买入时间 / 季节 |
| `wear_freq` | 常穿频次：高 / 中 / 低 / 几乎不穿 |
| `surface` | 表面处理：哑光 / 亮面 / 半亮（机能风必填） |
| `hardness` | 硬壳 / 软壳 / 无壳（机能风必填） |
| `has_logo` | 无 logo / 小 logo / 大 logo（老钱风必填） |
| `note` | 自由备注 |

## 4. 录入协议

### 4.1 你说人话，我落字段

你说：「黑的冲锋衣两件、灰卫衣、西裤一条」

我不追问也能先落初稿，但**必须**对影响风格归属的字段追问。规则：

1. **一次最多问 3 个**，优先问决定风格归属的：
   - 冲锋衣 → 硬壳 / 软壳？哑光 / 亮面？长度？
   - 西裤 → 羊毛 / 混纺？有褶无褶？
   - 毛衣 → 纯羊毛 / 混纺 / 化纤？
2. 问不出来 → 标 `未确认`，继续往下走，不卡住
3. **第一次录入全量回显**；之后追加只回显新增那几条

### 4.2 回显格式

```
收到 4 件，落档如下（未确认的我标了，你看到了随时补）：

W001 外套·冲锋衣  黑/冷  尼龙涂层  硬壳·哑光  H型直筒  中厚/秋冬  正式度2  新
     限制：亮面五金，不进老钱
W002 上装·卫衣    灰/冷  棉质抓绒  宽松oversize  厚/冬  正式度1  尚可
     限制：袖口起球
W003 下装·西裤    藏蓝/冷  羊毛混纺  修身直筒  中厚/四季  正式度4  新
     限制：需干洗，别配机能鞋
W004 外套·冲锋衣  黑/冷  ——【未确认：硬壳还是软壳？哑光还是亮面？】

哪条对不上，直接说编号改。
```

### 4.3 发图录入

发图 → 我先识别，**不说死**，给：

- 主风格包 + 置信度（高 / 中 / 低）
- 次风格包（如果有）
- 低置信度时直接问：「这件更偏机能还是户外？你要我按哪个包搭？」

识别不出来就直说认不出品牌，不编造。

## 5. 搭配时的使用规则

出方案时：

1. 只从 `retired != true`、`condition` 不是「起球/变形」的件里挑
2. 每套必须能指到具体编号，说「配 W003」，不说「配条西裤」
3. `constraints` 是硬约束。例：W003 标了「别配机能鞋」，就不能在机能套里用它
4. 缺口照实说：宁可给「现有最接近方案 + 明确缺口」，不硬凑四不像
